# 省羊毛 · ShengYangMao

[访问 Sites 网站](https://shengyangmao.tarokiki.chatgpt.site)（当前仅站点所有者可访问）。公开源码与社区反馈：[GitHub](https://github.com/FlashPoint007/shengyangmao)。

每一份优惠，都有据可查。一个独立、开源的优惠与免费资源信息站，覆盖银行支付、生活消费、电商、AI 免费额度、游戏限免与数字工具。

## 功能

- 分类、全文关键词搜索、免费资源 / 地区过滤、核验与截止排序。
- 活动详情保留官方来源、资格、消费门槛、时间、操作步骤与限制。
- 本机收藏、参与标记、信源关注；无注册、无第三方分析脚本。
- 截止日历与 `.ics` 导出、链接分享、GitHub 投稿与失效反馈。
- 40 个分级信源，明确区分已人工收录与待接入。
- `/api/catalog` 开放结构化数据，`/api/source-health` 读取公开仓库的巡检记录。

## 当前数据范围

首批 10 条人工整理的活动 / 官方入口，2026-11-09 核对。7 条核对公开规则，3 条只确认官方入口；**核对不保证个人资格或实时名额**。不虚构全网实时采集、领取人数和券库存。

`data/catalog.json` 是活动权威数据，`data/sources.json` 是信源目录。已结束按官方截止时间判断；7 天未复核自动显示“待复核”。规则核对时间只可在人工复核后更新。`public/data/` 提供静态副本，修改活动后需同步副本并重新部署。

## 本地开发

需要 Node.js 22.13+。

```bash
npm ci
npm run dev
node scripts/validate-data.mjs
npx tsc --noEmit
npm run build
```

技术栈：React 19、TypeScript、Vinext / Vite、Cloudflare Worker。保留 Sites 构建集成；部署配置在 `.openai/hosting.json`。该文件包含站点 ID，不含凭证。复用本项目创建新站时请移除旧 `project_id`，用新站返回 ID 替换。不要提交 `.env`、部署凭证、私有日志或个人信息。

## 信源策略

| 级别 | 来源 | 使用方式 |
| --- | --- | --- |
| P0 | 银行、商家、AI 厂商、游戏商店官方页面 | 规则核验依据 |
| P1 | 什么值得买、V2EX、LINUX DO | 发现线索，回溯官方后发布 |
| P2 | 用户 GitHub 投稿 | 人工审核，不自动发布 |

不采集登录后私有内容，不绕过反爬 / CAPTCHA / 访问控制；未开放 API 的 App 活动人工核验。不收录赌博、拉人头、违规套现和虚假免费。

## 自动公开页巡检

`.github/workflows/source-check.yml` 在北京时间每天 10:00、相关规则文件推送及手动触发时，低频检查已收录原文的可访问性，存储状态、时间与 SHA-256，不保存完整第三方网页。外链跳转仅允许已批准的 HTTPS 官方域名，最多 3 次，响应体上限 2 MB。

HTTP 成功不等于活动有效；哈希变化也可能是动态内容。工作流**不会自动把活动标为已核验或刷新人工核验时间**。网站最多缓存巡检结果 5 分钟，无记录或失败时明确显示暂无记录。GitHub 定时执行可能延迟；工作流尚未运行时不可宣称自动巡检已上线。

公开仓库已发布，`data/catalog.json` 的 `repositoryReady` 为 `true`，已开放代码、投稿及失效反馈入口。

首次源码推送会触发巡检；在 Actions 中确认实际结果，失败时不会伪造成功记录。后续数据更新需要人工评审与 Sites 再发布；当前不具备从 GitHub 推送自动部署 Sites 的功能。
